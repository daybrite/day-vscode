## The `day` CLI

Every build, launch, lint and toolchain check this extension performs runs the `day` CLI. It is not
a prerequisite: **Install/Update the Day CLI** can put one in the extension's own storage, leaving
your `PATH` and any `day` you installed yourself untouched.

- [Getting the CLI](https://vscode.daybrite.dev/docs/install) — every route, and which to pick
- [Getting started with Day](https://daybrite.dev/docs/getting-started/) — the framework itself
- [System requirements](https://daybrite.dev/docs/system-requirements/) — what each platform needs
